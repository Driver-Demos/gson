
## Files
- **[BagOfPrimitives.java](metrics/BagOfPrimitives.java.driver.md)**: The `BagOfPrimitives.java` file defines a class with several primitive fields and provides methods for JSON representation, equality checks, and string representation.
- **[BagOfPrimitivesDeserializationBenchmark.java](metrics/BagOfPrimitivesDeserializationBenchmark.java.driver.md)**: The `BagOfPrimitivesDeserializationBenchmark.java` file contains Caliper-based micro-benchmarks for measuring the performance of Gson's deserialization of a `BagOfPrimitives` object using different methods, including default deserialization, manual streaming, and reflection streaming.
- **[CollectionsDeserializationBenchmark.java](metrics/CollectionsDeserializationBenchmark.java.driver.md)**: The `CollectionsDeserializationBenchmark.java` file contains Caliper-based micro-benchmarks for measuring the performance of Gson in deserializing collections of `BagOfPrimitives` objects using different methods, including default deserialization, streaming, and reflection streaming.
- **[NonUploadingCaliperRunner.java](metrics/NonUploadingCaliperRunner.java.driver.md)**: The `NonUploadingCaliperRunner.java` file in the `gson` codebase provides a utility to run Caliper benchmarks without uploading the results, by modifying the arguments passed to the CaliperMain class.
- **[ParseBenchmark.java](metrics/ParseBenchmark.java.driver.md)**: The `ParseBenchmark.java` file in the `gson` codebase measures the parsing and binding performance of Gson and Jackson libraries using various parsing strategies on Twitter feed data.
- **[SerializationBenchmark.java](metrics/SerializationBenchmark.java.driver.md)**: The `SerializationBenchmark.java` file contains Caliper-based micro-benchmarks for testing the performance of Gson serialization with optional pretty printing.
