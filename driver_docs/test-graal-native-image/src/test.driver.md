## Folders
- **[java](test/java.driver.md)**: The `java` folder in the `gson` codebase contains a `com` directory focused on JUnit tests for Gson's serialization and deserialization capabilities, especially concerning Java 17 records and classes.
- **[resources](test/resources.driver.md)**: The `resources` folder in the `gson` codebase contains a `META-INF` directory with configuration files for GraalVM native image reflection.
