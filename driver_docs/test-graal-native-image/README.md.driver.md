# Purpose
The provided content is a documentation excerpt for a Maven module dedicated to running integration tests for the Gson library within a GraalVM Native Image environment. This module is specifically designed to handle the complexities of executing tests that involve reflection, which is a common requirement when using GraalVM's Native Image capabilities. The document explains that while these tests are not enabled by default due to their resource-intensive nature, they can be executed by configuring the environment to use GraalVM and activating a specific Maven profile. It also highlights the necessity of maintaining reflection metadata, which is crucial for Native Image creation, and points to a JSON file that contains this metadata. Additionally, it provides an option to use a Maven plugin to automatically generate the required metadata, facilitating easier management of reflection configurations.
