## Folders
- **[ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE.driver.md)**: The `ISSUE_TEMPLATE` folder in the `gson` codebase contains GitHub issue templates and configuration files to guide users in reporting bugs, requesting features, and seeking support for the Gson project.
- **[workflows](.github/workflows.driver.md)**: The `workflows` folder in the `gson` codebase contains GitHub Actions workflow files for building the project, checking Android and API compatibility, running fuzz tests, and performing CodeQL analysis.

## Files
- **[dependabot.yml](.github/dependabot.yml.driver.md)**: The `dependabot.yml` file in the `gson` codebase configures Dependabot to update Maven dependencies and GitHub Actions on a monthly schedule, grouping them into single pull requests.
- **[pull_request_template.md](.github/pull_request_template.md.driver.md)**: The `pull_request_template.md` file in the `gson` codebase provides a structured template for contributors to follow when submitting pull requests, including sections for purpose, description, and a checklist to ensure code quality and compliance with guidelines.
