## Folders
- **[main](src/main.driver.md)**: The `main` folder in the `gson` codebase contains the `java` directory, which houses Java files for demonstrating and testing Gson's serialization and deserialization capabilities.
- **[test](src/test.driver.md)**: The `test` folder in the `gson` codebase contains the `java` directory, which includes integration tests for validating the functionality of shrunken and obfuscated JARs with ProGuard and R8.
