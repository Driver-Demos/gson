# Purpose
This file contains configuration rules for ProGuard and R8, which are tools used in Java development to optimize and obfuscate code. The rules specified here are tailored specifically for integration testing purposes within the codebase, ensuring that only necessary modifications are made for testing, while general rules applicable to all users are maintained separately in the `META-INF/proguard` directory of Gson. The file includes directives to allow access modification, prevent issues with mixed case class names on Windows, and ignore notes about duplicate JDK classes. It also specifies rules to retain certain classes and class members, particularly those related to test entry points and fields that should be preserved during code shrinking, ensuring that essential components remain intact for testing and reflection purposes.
