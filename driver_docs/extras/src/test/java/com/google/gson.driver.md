## Folders
- **[graph](gson/graph.driver.md)**: The `graph` folder in the `gson` codebase contains a test file, `GraphAdapterBuilderTest.java`, which includes JUnit tests for the `GraphAdapterBuilder` to ensure correct serialization and deserialization of object graphs in the Gson library.
- **[interceptors](gson/interceptors.driver.md)**: The `interceptors` folder in the `gson` codebase contains a test file, `InterceptorTest.java`, which provides unit tests for the `Intercept` and `JsonPostDeserializer` functionalities to ensure correct deserialization and validation of `User` and `Address` objects.
- **[typeadapters](gson/typeadapters.driver.md)**: The `typeadapters` folder in the `gson` codebase contains unit test files for various type adapter factories and adapters in the Gson library, ensuring correct serialization and deserialization of objects, handling of polymorphic types, and date conversions.
