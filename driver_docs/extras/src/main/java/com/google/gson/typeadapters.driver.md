
## Files
- **[PostConstructAdapterFactory.java](typeadapters/PostConstructAdapterFactory.java.driver.md)**: The `PostConstructAdapterFactory.java` file in the `gson` codebase provides a `TypeAdapterFactory` implementation that creates a `TypeAdapter` capable of invoking methods annotated with `@PostConstruct` after deserialization.
- **[RuntimeTypeAdapterFactory.java](typeadapters/RuntimeTypeAdapterFactory.java.driver.md)**: The `RuntimeTypeAdapterFactory.java` file in the `gson` codebase provides a mechanism for serializing and deserializing polymorphic objects by adding and honoring type information in JSON, allowing for the differentiation of runtime types from their declared types.
- **[UtcDateTypeAdapter.java](typeadapters/UtcDateTypeAdapter.java.driver.md)**: The `UtcDateTypeAdapter.java` file in the `gson` codebase provides a custom `TypeAdapter` for serializing and deserializing `Date` objects in UTC format using ISO-8601 standards.
