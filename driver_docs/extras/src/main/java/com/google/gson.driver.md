## Folders
- **[extras](gson/extras.driver.md)**: The `extras` folder in the `gson` codebase contains an `examples` directory that provides a Java example for using Gson to handle serialization and deserialization of raw collections with mixed data types.
- **[graph](gson/graph.driver.md)**: The `graph` folder in the `gson` codebase contains the `GraphAdapterBuilder.java` file, which provides functionality for building graph-aware type adapters to handle cyclic references in object serialization and deserialization.
- **[interceptors](gson/interceptors.driver.md)**: The `interceptors` folder in the `gson` codebase contains files that define annotations and interfaces for implementing post-deserialization processing of JSON objects using interceptors.
- **[typeadapters](gson/typeadapters.driver.md)**: The `typeadapters` folder in the `gson` codebase contains Java files that implement custom `TypeAdapterFactory` and `TypeAdapter` classes for handling specific serialization and deserialization scenarios, such as invoking `@PostConstruct` methods, managing polymorphic types, and formatting `Date` objects in UTC.
