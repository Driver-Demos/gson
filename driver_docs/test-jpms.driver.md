## Folders
- **[src](test-jpms/src.driver.md)**: The `src` folder in the `gson` codebase contains the `main` and `test` folders, which are used for maintaining module compatibility and testing the Java Platform Module System, respectively.

## Files
- **[pom.xml](test-jpms/pom.xml.driver.md)**: The `pom.xml` file in the `gson/test-jpms` directory configures a Maven project for testing the Java Platform Module System (JPMS) with dependencies on Gson, JUnit, and Truth.
- **[README.md](test-jpms/README.md.driver.md)**: The `README.md` file in the `gson/test-jpms` directory explains that this Maven module contains tests to ensure that Gson's `module-info.class` is compatible with the Java Platform Module System (JPMS) and can be utilized by other projects.
