
## Files
- **[annotations.proto](proto/annotations.proto.driver.md)**: The `annotations.proto` file defines protocol buffer extensions for customizing field and enum value serialization names in the `gson` codebase.
- **[bag.proto](proto/bag.proto.driver.md)**: The `bag.proto` file defines several protocol buffer messages with various fields, annotations, and nested structures for testing purposes in the `gson` codebase.
