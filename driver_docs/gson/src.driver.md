## Folders
- **[main](src/main.driver.md)**: The `main` folder in the `gson` codebase contains the core Java components for JSON processing, internal build configuration templates, and resource files for code optimization.
- **[test](src/test.driver.md)**: The `test` folder in the `gson` codebase contains resources and Java files dedicated to testing the functionality and performance of the Gson library, including ProGuard configuration for test cases.
