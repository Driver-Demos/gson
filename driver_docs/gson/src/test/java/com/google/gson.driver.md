## Folders
- **[common](gson/common.driver.md)**: The `common` folder in the `gson` codebase contains utility files for testing, including `MoreAsserts.java` for additional assertion methods and `TestTypes.java` for defining classes and serializers to test JSON serialization and deserialization.
- **[functional](gson/functional.driver.md)**: The `functional` folder in the `gson` codebase contains a comprehensive suite of functional and unit tests for the Gson library, covering a wide range of serialization and deserialization scenarios, including arrays, collections, custom type adapters, concurrency, enums, formatting, internationalization, Java 17 records, JSON parsing, security, and versioning.
- **[integration](gson/integration.driver.md)**: The `integration` folder in the `gson` codebase contains integration tests, specifically the `OSGiManifestIT.java` file, which verifies the attributes of the generated OSGi manifest for the Gson library.
- **[internal](gson/internal.driver.md)**: The `internal` folder in the `gson` codebase is dedicated to unit testing various internal components and utilities of the Gson library, including JSON processing, reflection utilities, SQL type support, and specific classes like `ConstructorConstructor`, `GsonTypes`, `JavaVersion`, `LazilyParsedNumber`, `LinkedTreeMap`, `Streams`, and `UnsafeAllocator`.
- **[metrics](gson/metrics.driver.md)**: The `metrics` folder in the `gson` codebase contains the `PerformanceTest.java` file, which includes performance tests for the Gson library's serialization and deserialization processes, though these tests are currently disabled.
- **[reflect](gson/reflect.driver.md)**: The `reflect` folder in the `gson` codebase contains the `TypeTokenTest.java` file, which provides unit tests for the `TypeToken` class to ensure its correct functionality with different types and variables.
- **[stream](gson/stream.driver.md)**: The `stream` folder in the `gson` codebase contains unit tests for the `JsonReader` and `JsonWriter` classes, focusing on their functionality and behavior under various conditions.
