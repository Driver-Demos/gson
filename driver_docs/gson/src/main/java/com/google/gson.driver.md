## Folders
- **[annotations](gson/annotations.driver.md)**: The `annotations` folder in the `gson` codebase contains Java files that define various annotations used in the Gson library for managing JSON serialization and deserialization, including field exposure, custom adapters, field naming, and version control.
- **[internal](gson/internal.driver.md)**: The `internal` folder in the `gson` codebase contains a collection of Java files and subfolders that provide internal utilities, type adapters, reflection helpers, and other functionalities essential for the Gson library's JSON serialization and deserialization processes.
- **[reflect](gson/reflect.driver.md)**: The `reflect` folder in the `gson` codebase contains utility classes for handling and retrieving type information for generic types, including metadata documentation in `package-info.java` and a mechanism for working with generic types in `TypeToken.java`.
- **[stream](gson/stream.driver.md)**: The `stream` folder in the `gson` codebase contains classes and interfaces for efficient streaming processing of JSON, including reading and writing JSON data, handling JSON tokens and scopes, and managing exceptions for malformed JSON.
