## Folders
- **[bind](internal/bind.driver.md)**: The `bind` folder in the `gson` codebase contains various Java files and a utility subfolder, all focused on providing type adapters and factories for serializing and deserializing different data structures and types in JSON using the Gson library.
- **[reflect](internal/reflect.driver.md)**: The `reflect` folder in the `gson` codebase contains the `ReflectionHelper.java` file, which provides utility methods for handling reflection operations.
- **[sql](internal/sql.driver.md)**: The `sql` folder in the `gson` codebase contains Java files that implement custom Gson `TypeAdapters` for handling serialization and deserialization of SQL date, time, and timestamp objects, along with support for `java.sql` types compatibility.

## Files
- **[ConstructorConstructor.java](internal/ConstructorConstructor.java.driver.md)**: The `ConstructorConstructor.java` file in the `gson` codebase provides functionality to create object constructors for various types, including handling special cases for collections and maps, and supports the use of JDK Unsafe for instantiation when permitted.
- **[Excluder.java](internal/Excluder.java.driver.md)**: The `Excluder.java` file in the `gson` codebase defines a class that determines which fields and types to omit during serialization and deserialization based on various criteria such as version annotations, field modifiers, and custom exclusion strategies.
- **[GsonPreconditions.java](internal/GsonPreconditions.java.driver.md)**: The `GsonPreconditions.java` file provides utility methods for checking method preconditions, such as ensuring arguments are not null or invalid, within the Gson library.
- **[GsonTypes.java](internal/GsonTypes.java.driver.md)**: The `GsonTypes.java` file provides static utility methods for working with Java types, including creating parameterized types, generic array types, and wildcard types, as well as resolving and comparing types.
- **[JavaVersion.java](internal/JavaVersion.java.driver.md)**: The `JavaVersion.java` file in the `gson` codebase provides utility methods to determine the major Java version of the current JVM and check if it is Java 9 or later.
- **[JsonReaderInternalAccess.java](internal/JsonReaderInternalAccess.java.driver.md)**: The `JsonReaderInternalAccess.java` file defines an abstract class that provides internal-only APIs for the `JsonReader` class within the Gson library, including a method to change the type of the current property name token to a string value.
- **[LazilyParsedNumber.java](internal/LazilyParsedNumber.java.driver.md)**: The `LazilyParsedNumber.java` file in the `gson` codebase defines a class that represents a number value stored as a string, which is lazily converted to specific number types like int, long, float, or double when needed.
- **[LinkedTreeMap.java](internal/LinkedTreeMap.java.driver.md)**: The `LinkedTreeMap.java` file in the `gson` codebase implements a map data structure that maintains insertion order for iteration while using a tree structure for efficient insertion and removal, and it supports comparable keys and optionally allows null values.
- **[NonNullElementWrapperList.java](internal/NonNullElementWrapperList.java.driver.md)**: The `NonNullElementWrapperList.java` file defines a list wrapper that prevents the insertion of null elements while maintaining the functionality of a standard list.
- **[NumberLimits.java](internal/NumberLimits.java.driver.md)**: The `NumberLimits.java` file defines a class that enforces limits on the size and scale of numbers parsed from JSON to prevent performance issues with extremely large numbers.
- **[ObjectConstructor.java](internal/ObjectConstructor.java.driver.md)**: The `ObjectConstructor.java` file defines an interface for creating default instances of classes to facilitate object navigation during JSON deserialization in the Gson library.
- **[package-info.java](internal/package-info.java.driver.md)**: The `package-info.java` file in the `gson` codebase provides a warning that the classes in the `com.google.gson.internal` package are intended for internal use only and may change incompatibly in future versions.
- **[PreJava9DateFormatProvider.java](internal/PreJava9DateFormatProvider.java.driver.md)**: The `PreJava9DateFormatProvider.java` file provides date and time formatting for the US locale using patterns that were default in Java 8 and earlier versions.
- **[Primitives.java](internal/Primitives.java.driver.md)**: The `Primitives.java` file in the `gson` codebase provides utility methods for determining if a type is a primitive or a wrapper type, and for converting between primitive types and their corresponding wrapper types.
- **[ReflectionAccessFilterHelper.java](internal/ReflectionAccessFilterHelper.java.driver.md)**: The `ReflectionAccessFilterHelper.java` file in the `gson` codebase provides utility methods for determining platform types and applying reflection access filters, as well as checking accessibility of objects in Java.
- **[Streams.java](internal/Streams.java.driver.md)**: The `Streams.java` file in the `gson` codebase provides functionality for reading and writing GSON parse trees over streams, including methods to parse JSON from a `JsonReader` and write JSON elements to a `JsonWriter`, as well as adapting an `Appendable` to a `Writer`.
- **[TroubleshootingGuide.java](internal/TroubleshootingGuide.java.driver.md)**: The `TroubleshootingGuide.java` file provides a utility method to create URLs pointing to specific sections of the Gson troubleshooting guide on GitHub.
- **[UnsafeAllocator.java](internal/UnsafeAllocator.java.driver.md)**: The `UnsafeAllocator.java` file in the `gson` codebase provides an abstract class for allocating objects without invoking their constructors, using various methods depending on the runtime environment.
